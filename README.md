# Central Agro Dados

Repositório usado somente como armazenamento dos arquivos JSON do Central Agro.

Este repositório não deve ser conectado ao Vercel para deploy automático.

Estrutura prevista:

```text
/data-live/status.json
/data-live/produtos.json
/data-live/ticket.json
/data-live/indicadores.json
/data-live/racao.json
/data-live/milho.json
/data-live/vacinas.json
```
